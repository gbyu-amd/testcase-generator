| [PRD] 配置项 - 横轴变量 | 接收1个定量/定类变量 | 放入横轴变量，变量区域正确显示变量名；删除横轴变量成功，变量区域为空 |

| [PRD] 配置项 - 控制限设置 | 默认勾选UCL、LCL，UCL为97.5%分位数，LCL为2.5%分位数 | 控制限设置默认勾选UCL、LCL，UCL为97.5%分位数，LCL为2.5%分位数 |
| [PRD] 配置项 - 小数位数 | 默认3，选项1-5 | 小数位数默认值为3，下拉选项正确 |
| [PRD] 分析结果展示 | 开始分析后按配置生成结果，配置页面刷新 | 百分位数控制图分析完成，分析结果页面结构正确；排列配置为"无/阶段/自定义范围"时分析结果展示正确 |
| [PRD] 分析结果页面结构 | 分析流程（数据源、算法配置、分析结果）+ 详细结论（分析图表、过程数据、超出参考线检查） | 百分位数控制图分析完成，分析结果页面结构正确；【待确认】过程数据字段显示正确；【待确认】超出参考线检查显示正确 |
| [PRD] 分析流程限制 | 已生成的分析结果不可在原有配置基础上修改或继续分析 | 分析流程限制：已生成的分析结果不可修改或继续分析 |
| [PRD] 异常 - 数据范围不存在 | 切换横轴变量、自定义参考线切换横轴、阶段字段更新时阻止分析 | 已存在自定义范围类型的参考线，切换横轴变量后，不支持分析；已存在自定义范围类型的参考线，清空横轴变量后，不支持分析 |
| [PRD] 异常 - 数据范围有交叉 | 自定义参考线边界值交叉时阻止添加 | 第一个和第二个范围存在数据交叉，给出提示；自定义参考线设置中数据范围有交叉，阻止添加该参考线 |
| [PRD] 异常 - 纵轴变量数据缺失 | 静默排除缺失值 | 纵轴变量数据缺失，分析时静默排除缺失值；纵轴变量选择混合型数据列，分析成功，验证分析结果正确 |
| [PRD] 异常 - 横轴变量数据缺失 | 分析图横轴缺失值位置显示为"*" | 横轴变量数据缺失，分析图横轴对应缺失值的位置显示为"*" |
| [PRD] 异常 - 特殊数据格式 | 时:分:秒→分钟，%→小数 | 特殊数据格式（时:分:秒、%），分析前自动转换 |
| [PRD] 异常 - 没有足够的数据 | 只有一条或无有效数据时阻止分析 | 纵轴变量只有一条或无有效数据，不支持分析 |
| [PRD] 异常 - 阶段数量超过5个 | 阻止分析并提示 | 阶段数量超过5个时不支持分析 |
| [PRD] 后置处理 - 结果保存和回传 | 分析结果可保存，可回传给其他系统 | 百分位数控制图分析完成，推送至业务系统成功；推送后预览分析结果，详细结论和输入结论显示正确 |
| [PRD] 不同数据类型支持 | 小数、负数、混合型数据列分析 | 纵轴变量选择小数列，分析成功；纵轴变量选择负数列，分析成功；纵轴变量选择混合型数据列，分析成功 |

| [回查] 数据源预览 | 详情页数据源预览 | 从数据分析工作台进入数据分析详情页，数据源处预览数据，显示正确 |
